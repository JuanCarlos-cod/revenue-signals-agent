# Aclaración sobre captura de rate_input Web

**ID:** F19
**Fecha:** 2026-09-30
**Tipo:** Correo
**Área:** Canales Digitales

Canales Digitales aclara que la captura mencionada en el hilo de Teams corresponde al entorno de certificación, no a producción. 
En producción, el campo rate_input del canal Web para Crédito Flexible contiene la tasa anual aprobada. Se solicita a Operaciones revisar si la diferencia de 
primas reportada se explica por saldos o fechas de desembolso.
